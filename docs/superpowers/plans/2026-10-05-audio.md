# Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A looping Lagos street ambience, audible warnings for incoming juju, and distinct sounds for oil, fuel, odeshi and both driver specials, each loading from an optional file and falling back to synthesis.

**Architecture:** A manifest (`src/config/sounds.ts`) names every sound and its optional file. A small sample store plus pure helpers (`src/game/audioLogic.ts`) decide file-or-synth and compute the juju warning mix; `src/game/audio.ts` owns the Web Audio context, buses, loops and `sfx()`. Game code (items, specials, RaceLogic) only calls audio functions, which are no-ops when the context is not unlocked, so existing tests keep passing.

**Tech Stack:** TypeScript, Web Audio API, vitest (node environment, no AudioContext).

**Spec:** `docs/superpowers/specs/2026-10-05-audio-design.md`

## Global Constraints

- No musical soundtrack; ambience is traffic pings, shouting, generator hum.
- Missing or failed audio files must never throw; the synth sound plays instead.
- Audio files: mono ogg/mp3 in `public/audio/`, whole set under about 1 MB, loaded lazily after the first user gesture, ambience first.
- Ambience sits low under the engine and ducks slightly during special and hit sounds.
- The existing mute (`setSoundEnabled`) silences everything including loops.
- "Foil" means the fuel boost item. Out of scope: music, per-track beds, sachet projectile.
- Sounds are for the local player's car; an opponent slipping or being hit is also audible when the local player is the owner (existing behaviour) or the victim.

## Review Focus

- Race ends, player is eliminated or leaves while a juju is mid-flight: the hum loop must stop.
- Two jujus aimed at the player: one hum, driven by the nearest.
- Audio not yet unlocked (no tap yet), or sound muted: every new function is a silent no-op, no throw.
- Sample file 404s or fails to decode: synth fallback plays, no unhandled rejection.
- Starting a second race (retry, next campaign race): ambience restarts once, never stacks two beds.

### Task 2: Mixer, loops and synth fallbacks in `audio.ts`

**Files:**
- Modify: `src/game/audio.ts`
- Test: none (needs a real AudioContext); verified in Task 6 by browser check.

**Interfaces:**
- Consumes: Task 1 `SOUNDS`, `createSampleStore`, `SoundName`.
- Produces (all silent no-ops when the context is missing or muted):
  - `sfx(kind)` extended with `'jujuHit' | 'oilDrop' | 'oilSlip' | 'fuelBoost' | 'odeshiBreak'` (existing kinds unchanged); each plays its manifest file if loaded, else a synth sound.
  - `startAmbience(): void` and `stopAmbience(): void` — idempotent; `startAmbience` while running does nothing.
  - `class Loop { constructor(name: 'jujuFly' | 'soupBubble'); start(): void; set(gain: number, rate: number, pan: number): void; stop(): void }`
  - `duck(seconds: number): void` — lowers the ambience bus to about 55% for `seconds`, then restores.
  - `Engine.setBoost(on: boolean): void` — raises the engine pitch about 25% while on.
  - `loadSounds(): void` — starts the lazy file loads (ambience first); called from `unlockAudio`.

- [ ] **Step 1: Add buses.** In `unlockAudio`, create `ambienceBus`, `sfxBus`, `engineBus` gains into `master` (ambience 0.35, sfx 1, engine 1). Route `tone`/`noise`/`bleat` through `sfxBus` and `Engine` through `engineBus`. Existing `setSoundEnabled` still sets only `master`.
- [ ] **Step 2: Sample playback helper** `play(name, opts?)`: if `store.get(name)` exists, play it once on `sfxBus` at `SOUNDS[name].volume`; return whether it did. Each new `sfx` kind calls `play` first and runs its synth only when it returns false.
- [ ] **Step 3: Synth fallbacks.** `oilDrop`: low gloopy sine drop plus short filtered noise. `oilSlip`: the existing `slip` sound with a longer falling squeal. `jujuHit`: the existing `juju` sound, louder, with a low thump. `fuelBoost`: the existing `boost` sound. `odeshiBreak`: three descending sine tones plus a noise crackle. Keep the existing `oil`, `slip`, `juju`, `odeshi`, `boost`, `push`, `soup` kinds working; make `push` add a stomp pattern (three low noise hits 0.12 s apart) and `soup` add a sizzle (high filtered noise burst).
- [ ] **Step 4: Ambience.** If `ambience` is loaded, loop it on `ambienceBus`. Otherwise run a synth bed: looped noise through a lowpass at about 500 Hz at low gain for murmur, plus a `setTimeout` scheduler that plays a quiet horn ping (reuse `tone` square, 520 or 620 Hz, 0.15 s) every 3 to 9 s at random until stopped. Starting a second time while running returns early; `stopAmbience` clears the timer and stops sources.
- [ ] **Step 5: `Loop`.** File loop if loaded, else a synth loop (`jujuFly`: detuned sine plus triangle with slow vibrato; `soupBubble`: bandpassed noise with random gain bursts). Routes through a `StereoPannerNode` into `sfxBus`; `set` ramps gain, playbackRate or detune, and pan over 0.05 s; `stop` fades out and disconnects. Safe to call `stop` twice.
- [ ] **Step 6: `duck`, `Engine.setBoost`, `loadSounds`.** `loadSounds` fetches with `fetch(url).then(r => r.ok ? r.arrayBuffer() : Promise.reject())` and `ctx.decodeAudioData`, ambience first, errors swallowed by the store. Call it at the end of `unlockAudio`.
- [ ] **Step 7: Verify** `npx tsc --noEmit` and `npx vitest run` — expect no type errors and all existing tests PASS (they run without a context).
- [ ] **Step 8: Commit** `git add src/game/audio.ts && git commit -m "feat(audio): buses, ambience, loops, file-or-synth sounds"`
