# Campaign (Chapter 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-player campaign whose Chapter 1 is four races on Ojuelegba and Ikorodu Garage, adding an elimination mode and a Mama Put duel, and unlocking Mama Put as a driver when she is beaten.

**Architecture:** Race modes (`laps`, `elimination`, `duel`) are small pure modules in `src/game/modes.ts` that work on a structural view a `RaceRuntime` already satisfies, so they are unit-tested without Three.js. Campaign data lives in `src/config/campaign.ts` and its pure rules (pass, coins, unlocks, progress) in `src/game/campaign.ts`. `makeRace` moves to the testable `src/game/setup.ts` and builds the grid from a spec; the scene, HUD and screens then follow the pure logic.

**Tech Stack:** Vite, React, TypeScript, zustand, React Three Fiber and Rapier, Vitest (`npx vitest run`, `npm run typecheck`).

**Spec:** `docs/superpowers/specs/2026-10-04-campaign-design.md` (GitHub issue #4)

## Global Constraints

- Chapter 1 (ids, titles, tracks, modes, pass): `campaign-1-1` "Ojuelegba Hustle" `ojuelegba` laps 3, place ≤ 3; `campaign-1-2` "Ikorodu Garage Run" `ikorodu` laps 3, place ≤ 3; `campaign-1-3` "LASTMA Is Coming" `ojuelegba` elimination, place ≤ 3; `campaign-1-4` "Mama Put's Challenge" `ikorodu` duel, 2 laps, place = 1. Race N+1 opens when race N is cleared; cleared races can be replayed.
- Coins: place table `[150, 100, 60, 30, 20]` (last entry repeats) for races 1–3 and quick race; duel `[200, 40]`. First-clear bonus, paid once: +100 for races 1–3, +300 for the duel. Coins are paid on every attempt, passed or not.
- Elimination: 6 racers, no lap limit (`config.laps = Infinity`), timer `first 20 s`, shortens by `step 2 s` per round, floor `10 s`: `interval(round) = max(10, 20 − 2 × round)`, round counted from 0. Lowest unwrapped `progress.distance` among racers still in is out (exact tie: lower id). Race over when one racer is left or the player is out. Ranking: those still in by distance, then the eliminated in reverse knock-out order (out in the 2nd round of 6 means 4 still in, so 5th).
- Duel: 2 racers side by side on the front row, Mama Put drives the player's vehicle in a different paint, driver `mamaput`, AI skill `1.06`, no rubber band (`leaderGap` 0), items on, 2 laps. Placeholder lines: before "Oga, you go pay for that jollof."; she wins "Shine your eye, small boy."; you win "Next time carry your own pot."
- In campaign races 1–3 rivals never drive as Mama Put (`excludeDrivers: ['mamaput']`). Quick race is unchanged: any driver, saved `track`, coins table above, no bonus.
- Mama Put is locked until `campaign-1-4` is cleared. The lock is derived from `campaign.cleared` (no separate unlock list). A save with Mama Put selected and no clear falls back to Moshood.
- Save key stays `lagos-racer:v2`; add `campaign: { cleared: string[] }` in `normaliseSave`; old and junk saves must load. `?unlock=all` also marks every campaign race cleared.
- There are only two drivers (Moshood, Mama Put). No other new characters.
- Story text is placeholder (copy verbatim in Task 1). Coin amounts, the 20 s start and the duel skill are tuning numbers that live in config.
- Style: match the existing code (compact, comments only where the reason is not obvious). Tests sit next to the code (`src/game/race.test.ts` is the model). Check the UI at 812×375 (phone landscape) and 375×812, not just desktop.
- Commits are local only (never push unless the user asks) and end with the line `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Stage only the files each task lists.
- Overlap: `docs/superpowers/plans/2026-10-04-vehicle-upgrades.md` and `2026-10-03-multiplayer.md` (neither started) edit some of the same files. Check `git log` for either before starting a task that touches `store.ts`, `save.ts`, `RaceLogic.tsx`, `RaceScene.tsx`, `Results.tsx`, `Garage.tsx` or `Menu.tsx`, and merge rather than overwrite.

## Review Focus

- A corrupt or tampered `campaign` in a save (not an object, `cleared` not an array, unknown ids, duplicates, numbers) must load as no clears, never crash or unlock the duel: pinned in Tasks 1 and 3.
- Replaying a cleared race must not pay the first-clear bonus again or add a duplicate id; failing the duel (2nd) must not unlock Mama Put: pinned in Tasks 1 and 3.
- Elimination with negative distances (still behind the line), exact ties, and a huge `dt` (a frame hitch) must eliminate exactly one racer per due round, and nothing after the race is over: pinned in Task 2.
- Retrying a race must start with a fresh mode and fresh racers (timer back at 20 s, nobody `outAt`): pinned in Task 4.
- A racer with `outAt` of `0` is still out (`0` is falsy): pinned in Task 2.
